# Armor Power AP13000ET — UGC Video Package

## Files
- `script.md` — Full UGC script with voiceover + caption copy
- `video-prompts.md` — 10 Kling/Runway prompts, one per scene + editing order
- `voiceover.md` — ElevenLabs lines + text overlay guide

## Tools Needed (all have free tiers)
| Tool | Use | Sign Up |
|------|-----|---------|
| Kling AI | Video generation from prompts | kling.kuaishou.com |
| ElevenLabs | AI voiceover | elevenlabs.io |
| CapCut | Edit + stitch clips | capcut.com (free) |

## Production Steps
1. Generate all 10 video clips in Kling using prompts in `video-prompts.md`
2. Generate voiceover lines in ElevenLabs using `voiceover.md`
3. Import everything into CapCut
4. Arrange clips in order, drop voiceover on timeline
5. Add text overlays from `voiceover.md`
6. Add music (tense → triumphant arc)
7. Export 9:16 at 1080x1920
8. Post with caption from `script.md`
